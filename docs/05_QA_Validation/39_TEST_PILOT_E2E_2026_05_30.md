## 2. 검증 플로우

```text
/ko
  -> 테스트로 시작
  -> 샘플 데이터로 업로드 세션 생성
  -> TEE 분석 실행
  -> 분석 완료 후 dashboard 이동
  -> source-backed 추천 상품 표시
  -> 상품 선택
  -> checkout 이동
  -> 결제 없이 테스트 신청 완료
  -> 성공 화면 표시
```

1차 자동화는 dashboard까지 정상 도달했으나 상품 CTA locator가 좁게 잡혀 continuation script로 checkout 구간을 이어 실행했다. 앱 기능 오류가 아니라 자동화 locator 보강 이슈로 판단한다.

## 6. 발견 사항

| 항목 | 영향 | 후속 |
|---|---|---|
| Dashboard 상품 CTA 문구 | Test Pilot dashboard에서도 상품 선택 버튼이 `결제하기`로 보였다. checkout 이후 화면은 no-payment 문구로 정상 분기한다. | guest session일 때 dashboard CTA를 `테스트 신청하기`로 바꾸는 UI polish PR 권장 |
| 자동화 locator | 1차 Playwright script가 dashboard 이후 상품 CTA를 정확히 잡지 못해 continuation script로 완료했다. | 재사용 E2E spec 작성 시 카드/CTA에 안정적인 test id 추가 권장 |
| 운영 flag off 회귀 | 이번 검증은 Test Pilot flag on happy path만 확인했다. | production GA flag off 상태에서 운영 지갑/결제 플로우 회귀 테스트 필요 |
